# 连续预览与第三步交接（按用户最新确认修正）

## 当前按钮的准确含义

1. 始终在 A 点击编辑，点“预览修改”将本次修改累计到 B，可重复操作。
2. 点“保存修改副本”实际是确认本轮 B 并直接进入第三步“签名与证书”。
3. 此按钮不打开文件保存对话框，不选择文件名、不另行复制或导出 PDF。
4. 如果仍有未预览输入，先完成该输入的累计预览，再自动进入第三步；后台忙时保留进入请求。
5. B 沿用当前累计 PDF，A 保持原样；成功交接后结束本轮内容编辑。
6. 最终写出文件仍由后续签署/导出操作负责。退出软件前需完成实际导出；本按钮不代表已持久化到自选路径。

## 本次代码修正与中文注释

- `qt_context_editor.py::save_edit`：移除原来的 `QFileDialog.getSaveFileName` 和文件复制流程，改成流程确认请求。
- `_continue_actions`：待累计完成后调用 `_finish_editing`，不再调用 `_save_current_copy`。
- `_finish_editing`：保留当前 B，结束内容编辑，直接调用现有 `advance_to_signing`。
- 删除该 UI 中不再使用的保存目标、保存中状态、复制函数导入与旧保存回调，避免保留误触发分支。
- 仅生成必要的累计预览，不新增身份、签名或 CA 限制，不写 PDF 旁的修改记录。
- 更新回归用例：按钮不弹保存框、不写出文件，后台忙时保留跳转请求，待输入累计后进入第三步。
- 原子文件复制工具仍是独立工具，本按钮不再调用；没有删除其他功能需要的保存能力。
