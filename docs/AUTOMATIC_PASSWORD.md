# 新凭据自动密码（2026-11-01）

- “自动生成并签署 B”和单独“生成新密钥”无需填写密码。每套凭据在确认后由后台生成独立随机密码。
- PKCS#8 私钥和 P12 继续加密。密码通过 Windows DPAPI 当前用户保护，存入凭据目录的 `.qpdf-password.dpapi`；不写入普通配置、报告或源码。
- 受保护记录绑定对应 P12 的 SHA-256。密码保护在所有密钥文件写入之前完成；保护失败不会留下丢失密码的新凭据。
- 使用本程序新生成的 P12 再次签署时自动读取；外部 P12 或旧凭据没有记录时仍输入其原密码，不改变已有密码。已有密钥重新签发入口仍使用其原密码。
- 保留整个凭据目录。同机同 Windows 用户使用；不承诺跨机器/账户可解密。复制 P12 本身不足以转移自动密码。保护记录损坏、丢失或账户不符时不会静默生成新密码替换。
- 未覆盖原 PDF、证书或已有凭据；未恢复证书类型拦截，未新增自动修改记录。

本次仅语法、导入、接线和部署 SHA 检查。按用户要求未执行 pytest、GUI、真实 DPAPI 密码保存、密钥生成或 PDF 签署验收。
