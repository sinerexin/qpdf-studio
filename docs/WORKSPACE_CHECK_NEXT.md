# 第三步右侧工作区：检测与进入第四步

- 右侧“A / B 验证结果”底部添加固定操作栏，按钮不随 A/B 结果内容滚出视野。
- “检测 A / B”：复用现有离线解析和验签函数，重新读取当前两侧实际文件并更新结果。不会生成签名、上传或重写 PDF。
- 此按钮是用户明确发起的检测，即使 B 尚未生成新签名，也检查当前 B；自动进入第三步时原有“生成 B 后自动检查”时机保持不变。
- 每次显式检测绑定当前文件版本，替换文件不继承旧的检测请求；后台繁忙时保留已有结果，按钮暂显示不可用。
- “进入第 4 步 →”：复用现有 `finish_signing`，切到“导出与对比”；不要求检查通过，不自动签署、保存或导出。
- 关键 UI 接线和状态分支均有中文注释，无新增身份/证书/CA 门槛。

本轮只进行语法、导入、静态接线和安装 SHA 核对。回归用例已编写但按此前要求未执行；未启动 GUI 或操作实际 PDF。
旧进程不热更新，需从桌面“qpdf Studio 最新版”重新打开加载按钮。
