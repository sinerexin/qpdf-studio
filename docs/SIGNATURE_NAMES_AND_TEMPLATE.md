# A/B 名称分段与 B 参考模板：中文代码说明

## 实际改动

### 1. `certificate_names.py`：A/B 共用名称规则
- `name_attributes`：读取 DN/RDN 属性，区分 CN、O、OU、C 等；保留重复属性和多值 RDN。
- `_split_dn` / `_display_attributes`：兼容已有长名称；只拆未转义的逗号/加号，解码名称转义，不把机构内部的逗号当成字段边界。
- `segment_name`：把 `名称第一段@名称第二段@标识` 分成多行；最后一段标为“标识”，不是证书序列号。空段和原始字符保留。
- `format_name`：签署者、持有人、签发者统一显示。邮箱作为邮箱保留，不误解释成主体标识。
- `display_name_fields`：详情显示“分段显示 + 完整原值”；不修改原始报告和 JSON 导出值。
- `build_subject`：生成新证书时沿用模板的主体属性，CN 使用本次确认的新名称；不复制原签发者的签名。
- 当前 cryptography 对新建 CN 有 UTF-8 字节长度检查；兼容构造沿用原名称，不自动截短、删段或添加产品门槛。未改变其他既有参数校验。

### 2. `signature_templates.py`：A 的完整参考信息与 B 的实际值分离
- `build_reference_template`：保留完整 A 信息作为参考，以 A 的名称前缀与本程序新生成的 `QPDF-…` 标识组成 B 待生成名称。
- 预览包括 A 的签名、证书、公钥和原始信息，均标为“A 参考模板，B 尚未生成”。预览不是 B 已写入的 PDF 内容，也不是 B 的验证结果。
- 只生成名称标识，不在导航/预览时创建密钥、证书或 PDF。
- `template_section`：详情可查看完整 A 参考信息；实际 B 数据不会被模板替换。

### 3. `qt_signature_cards.py` / `signature_card_data.py`：可见卡片
- `SummaryValue` 对名称开启多行显示，不再用省略号隐藏名称；完整原值保留在提示和详情中。
- `InformationCard` 动态增加行；公钥卡片增加持有人后，仍完整保留算法、位数、指数和 SPKI 指纹字段。
- A 和 B 使用同一控件、同一分段函数，没有两套不同的排版。
- B 未生成实际签名时显示带来源标记的 A 模板；有实际 B 数据后优先显示 B 的真实读取结果。
- 主卡片和完整信息对话框均使用名称分段格式。原始 JSON 导出仍保存实际原值。

### 4. `qt_signature_workspace.py`：刷新与选择联动
- A 切换签名或导入新的 A/B 时更新 B 模板。
- 普通界面刷新不重新随机生成标识，避免卡片和生成窗口对不上。
- 模板只用于信息显示，不注入右侧验证区的真实报告。

### 5. `qt_automatic_signing.py` / `automatic_signing.py` / `keygen.py`：预填与实际生成
- 生成窗口预填 B 卡片上的同一名称和标识；仍可修改名称。
- 原算法参考逻辑继续使用；主体 CN/O/OU 等可从模板传给新证书生成器。
- B 的新公钥、证书序列号、有效期和签名值仍来自本次实际生成。新证书的实际签发者是本地自签主体，不把 A 的 CA 签发签名复制成 B 的签发结果。
- 本次保留现有生成对话框和确认流程，没有擅自改成点击即写文件的一键签署。
- 没有添加新的签署、证书类型、身份名称或操作模式拦截。

### 6. `signature_evidence.py`：保留结构化名称
- 证书解析额外返回 `subject_attributes` 与 `issuer_attributes`，避免 UI 靠不准确的普通字符串拆分丢失原信息。

### 7. 测试代码
- 增加虚构名称分段、转义逗号、多值 RDN、模板新标识、A 数据不变、完整参考信息、五行公钥卡片等回归用例。
- 不包含用户真实 PDF、证书或银行正文。

## 具体显示示例（虚构数据）

原值：`CN=Demo@示例机构@N123,O=Example,C=CN`

- 通用名称（CN）
  - 名称 1：Demo
  - 名称 2：示例机构
  - 标识：N123
- 机构（O）：Example
- 国家（C）：CN

B 参考模板的最后一段替换为本程序创建的 `QPDF-…`，A 的原值不变。

## 检查与安装范围

新增逻辑有中文注释。按用户此前要求仅语法、导入、接线、安装 SHA 检查；没有运行 pytest、GUI、新密钥生成或真实 PDF 签署验收。没有改变已有 PDF、证书、私钥、密码或当前运行窗口。
